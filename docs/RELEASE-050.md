Try Vale Sangora from a first-person viewpoint, customise your companions' eye, hair and armour colours, or take your party through ten curated Horde waves.

- First-person camera toggle in Settings, with native dialogue and cutscene cameras preserved.
- Horde mode with varied enemies and bosses, adjustable wave sizes and rest times. Waves finish loading before combat, the menu closes when they are ready, and defeated bodies remain between waves.
- Eye, hair and armour colour selectors with saved choices and an original-colour reset.
- Separate Anca and Lacra romance conversation toggles. Each defaults to Off and turns On when the loaded save confirms that romance. You can also enable either profile early.
- Lunka, Lunka (Turned), Yanna, Mirto, Pieter and Esme join the Characters list. Non-fighting family members travel as protected companions. The combat-only catalogue now has 101 entries.
- Clear, centred character voices with gentle distance-based volume.
- Menu layout and navigation improvements, including Esc returning from Horde and Settings directly to gameplay.

Choose Complete for one download, or install both matching Scripts and Runtime ZIPs. Close the game, extract into its installation folder and merge the Dawnwalker folders. Reapply the matching optional Multilingual pack afterwards if you use it.

The Multilingual ZIP contains a character-ID configuration file and an installation note. The Source ZIP is for developers and contains no service key or compiled binaries. Existing appearance choices and keybindings are retained. The two romance settings replace the previous shared toggle.

Requirements: game 1.05, UE4SS for Dawnwalker 1.2.1 RC6, and Dawnwalker Mod Menu 1.0.6.2 or later. Conversations are free to use with the included shared service; no account or API key setup is required.
