# Native menu and configurable controls — 0.30.1

The original menu did not fill its viewport: overlay slots used their default alignment, the theme helper reset button fonts to 14, and selection brushes stayed transparent. The corrected layout explicitly fills its background and scaling slots, uses a 1920×1080 design, sets the final font size after applying the theme, and updates the native selection material on hover and keyboard selection. Game artwork, dividers, font and slider styling come from the installed Dawnwalker Mod Menu dependency; the page arrangement and interaction code belong to this mod.

Summon, Party, Settings, Controls and Help remain separate pages. Settings use native sliders and toggles. Hovering or selecting a row shows its explanation on the right. The background is opaque so the pause menu does not show through. Opening above a native pause menu temporarily disables that parent's input and restores it on close, preserving the game's pause state.

Keyboard routing no longer depends on PlayerController edge polling, which misses keys consumed by Slate or the pause interface. The helper handles the configurable menu shortcut, then installs its existing foreground-limited keyboard hook while the native panel is open. Menu key events are sent through a session-tagged local mailbox and consumed on EngineTick. Old events cannot act on a reopened panel. Escape cancels binding capture, returns to Summon from another page, then closes the root. The configured menu key closes directly; Enter chooses and arrows navigate or adjust values. The CommonUI host also releases when deactivated. Input capture expires if the game's menu heartbeat stops and never captures keys while another application is foreground.

`keybindings.ini`, beside the installed mod's `config.ini`, owns all five shortcuts. The Controls page and helper share this file. Valid hand edits reload automatically; unsupported, incomplete or duplicate mappings retain the last complete mapping. Voice indicators and Help show the assigned keys. F12 is excluded because Windows reserves it for debugging; see [RegisterHotKey documentation](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey). Letters and digits remain ordinary typed text while composing a message. Escape always closes the composer. Gameplay shortcuts may conflict with the game's own controls, so choose unused keys.

Validation: 25 focused Lua/chat/voice checks passed, plus the compiled helper's key-binding checks for parsing, persistence, duplicate/incomplete edits and recovery. The running game constructed all five pages and both rosters; slider initial values and final label sizes were checked. Runtime Escape dispatch passed cancellation, page-back and root-close checks. These are construction and routing checks, not a claim of visual approval or physical-key testing at every resolution. The user should check F5, Escape, sliders and one reassigned shortcut in the running game.

The workspace is now a local Git repository on `main`, with no configured remote. Extracted downloads, runtime state, credentials, generated executables and distribution archives are ignored and untracked. Commit source changes after validation; use `git log --oneline` and `git revert <commit>` for documented rollback.
